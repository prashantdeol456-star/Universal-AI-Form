# Implementation roadmap

The minimum end-to-end flow (spec §98) is the priority: signup → profile → upload document → extract → verify → open test
form → extension detects → local AI maps → Gemini handles a hard field → user confirms → fill → preview → confirm →
application saved → learning example saved. Advanced features come after that loop works.
